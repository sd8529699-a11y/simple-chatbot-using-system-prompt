An AI-powered chat application where users can log in and interact with an AI assistant by asking questions through a simple and user-friendly interface.

🚀 Features
Login Interface: A simple login page for users to access the application.
AI Chat Interface: After logging in, users can access the chat interface.
Prompt-Based Chat: Users can write prompts and ask questions to the AI assistant.
System Prompt: Uses a simple system prompt to guide the AI's responses.
User-Friendly UI: Clean and simple interface for a smooth chatting experience.
AI Responses: Get answers to user questions through AI integration.
⚙️ How It Works
Open the AI Chat Application.
Log in through the login interface.
After successful login, the chat interface will appear.
Enter your prompt or question in the input box.
Send the message to the AI assistant.
The AI processes the question using the configured system prompt and generates a response.
